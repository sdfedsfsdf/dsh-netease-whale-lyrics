# 鲸鱼歌词扩展（dsh-netease-whale-lyrics）

把小鲸鱼挂件变成一块**能滚动的歌词板**：网易云在放什么，鲸鱼的气泡就显示那一句。

- **持续输出**：气泡跟着播放逐句更新，暂停就收起
- **点击单次**：点一下鲸鱼，显示当前这一句，5 秒后自动收起
- 外文歌词自动附上中文翻译，长句按播放进度横向滚动，字号可调

这是 [dsh-whale-widget](https://www.npmjs.com/package/dsh-whale-widget) 与 `dsh-netease-music` 之间的**桥梁插件**，本身不提供音乐能力，也不包含鲸鱼本体。

当前版本 **0.1.6**。仓库：<https://github.com/sdfedsfsdf/dsh-netease-whale-lyrics>。

## 前提

| 依赖 | 说明 |
| --- | --- |
| dsh-whale-widget | 鲸鱼挂件本体，需单独安装（已按 0.4.2 验证） |
| dsh-netease-music | 提供进度与歌词，需单独安装 |
| DSH ≥ 0.1.7 / Node ≥ 20 | 运行环境 |

三个插件必须装在**同一个 profile** 里。

## 安装

```powershell
dsh plugin --profile desktop add "路径\dsh-netease-whale-lyrics-0.1.3.tgz"
```

然后**完全退出并重开 DSH**。进入聊天界面让鲸鱼初始化，打开鲸鱼菜单就能看到新增的「歌词模式」。

## 使用

1. 鲸鱼菜单 → **歌词模式**
2. 选 **持续输出** 或 **点击后单次输出**（默认关闭，关闭时完全不查询音乐）
3. 下方「歌词字号」滑杆：70%–160%，拖动即时预览，自动保存

| 模式 | 行为 |
| --- | --- |
| 关闭 | 不请求网易云接口，鲸鱼保持原有行为 |
| 持续输出 | 播放时逐句显示当前歌词；暂停、无歌词或失联时收起 |
| 点击后单次输出 | 点鲸鱼显示当前一句并保持 5 秒；再次点击取新的一句 |

细节：

- 原文一行；外文歌词下方显示中文译文，没有译文时提示「暂无中文翻译」
- 超长歌词按本句播放进度横向滚动，短句静止；点击模式按 5 秒展示时间滚动
- 字号随气泡尺寸缩放，再叠加滑杆倍率
- 预算提醒、每轮消耗、等待确认等系统气泡**优先于歌词**，不会被覆盖
- 拖动鲸鱼、长按菜单不会误触发歌词

## 注意事项

**这个扩展会修改鲸鱼插件的一个文件**

鲸鱼 0.4.2 没有公开的气泡/设置接口，因此扩展启动时会在已安装的
`node_modules/dsh-whale-widget/assets/whale-widget.js` 里注入一小段带标记的兼容桥：

- 只加桥和四处精确 hook，先做唯一锚点校验与语法检查才写入
- 首次写入时按鲸鱼版本备份原脚本
- 鲸鱼目录必须可写；升级鲸鱼会覆盖掉桥，重启 DSH 后扩展会自动重新检查安装
- 鲸鱼结构变化时**拒绝修改**并只记警告，不保证适配任意未来版本

**卸载与恢复**

停用扩展并刷新页面，设置项、轮询和点击接管立即消失，鲸鱼恢复原样；残留的桥在无人注册时不会接管任何行为。

想连桥一起清掉，先停用扩展，再在源码目录执行：

```powershell
node scripts/remove-bridge.mjs "C:\Users\你的用户名\.dsh\profiles\desktop"
```

刷新页面即可。脚本只移除桥标记与几个精确 hook，**不会**把旧备份覆盖回新版鲸鱼。

**其它**

- 翻译来自网易云，不是机器翻译；纯汉字日文无法仅凭字符可靠区分，有独立译文时仍会显示
- 时间戳对不齐的歌词可能拿不到译文
- 模式与字号保存在 **`$DSH_HOME/netease-whale-lyrics/settings.json`**，DSH 重启、端口变化都不会丢（0.1.4 起；更早版本存在浏览器 localStorage 里，换端口会重置成「关闭」）。
- 鲸鱼自身的「思考气泡」总开关必须打开，否则不会显示
- 无需保持网易云面板打开，但音乐插件与客户端必须可用

## 权限、外部服务与失败边界

这个扩展能力边界很清楚，提前说明白，方便你判断要不要装。

**会用到的东西**

| 能力 | 用在哪 | 范围 |
| --- | --- | --- |
| 文件读写 | 给鲸鱼脚本注入/移除兼容桥；读写自己的设置文件 | 仅 `node_modules/dsh-whale-widget/assets/whale-widget.js`（含同目录备份）与 `$DSH_HOME/netease-whale-lyrics/settings.json`，不碰其他路径 |
| 网络 | 浏览器端向**本机** DSH 发同源 HTTP 请求 | 只访问 `/api/netease-music/*` 与 `/api/netease-whale-lyrics/*`，不发往公网，不加载远程脚本 |
| 账号凭据 | 不接触 | 不读取 cookie、不登录、不代填账号；歌词与进度由已装好的 `dsh-netease-music` 提供 |
| 子进程 / 原生模块 | 不使用 | 无 shell、无 native 依赖、无生命周期安装脚本 |

**失败边界**

- 找不到鲸鱼插件、或鲸鱼脚本结构对不上：**拒绝修改**并只写一条警告，鲸鱼保持原样
- 鲸鱼目录不可写：注入失败但扩展照常加载，只是不显示歌词
- 音乐插件不可用 / 网易云没开 / 无歌词：气泡不显示或提示「暂无中文翻译」，不影响鲸鱼其他功能
- 停用扩展并刷新后，所有行为回到原状；兼容桥无人注册时不接管任何点击

**数据留存**：只保存 `mode` 与 `fontPercent` 两个字段，在本机 `settings.json`，不上传任何内容。

```powershell
node test.mjs "C:\Users\你的用户名\.dsh\profiles\desktop\node_modules\dsh-whale-widget\assets\whale-widget.js"
```

覆盖：桥补丁可逆/幂等、系统提示优先、歌词时间匹配、关闭时零请求、点击冻结、持续跟随、字号滑杆与持久化、卸载清理。
